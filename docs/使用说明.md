# Mac 打卡提醒使用说明

本次安装使用：周一至周五，上班 **10:10**、下班 **19:10**，使用 Mac 当前时区。

程序通过置顶窗口和渐强提示音提醒你打卡。**点击“已打卡”只保存本机确认，不会向公司考勤系统提交打卡。**

## 完成安装

双击安装包中的 `完成安装.command`。终端出现“安装完成”，且菜单栏显示“打卡”，表示常驻程序已运行。若处于紧急暂停期，菜单栏图标会在暂停结束后恢复。

这个入口在没有编译产物时自动构建，设置 10:10、19:10 和登录自启，保留现有确认记录。源码构建需要 Apple Command Line Tools；缺少时运行 `xcode-select --install`。若终端提示安装失败，保留错误文字，不要将其当作安装成功。

## 日常使用

1. 登录 Mac 后，程序自动在后台运行，菜单栏显示“打卡”。
2. 到提醒时间，屏幕出现打卡窗口。
3. 在公司的考勤软件或网页中完成打卡。窗口挡住页面时，拖动窗口顶部移开。
4. 回到提醒窗口，点击“已打卡”。保存成功后关闭当前提醒。

菜单栏的 `0/2`、`1/2`、`2/2` 表示今天已经确认的次数。若有其他遗漏提醒，会继续显示下一项；窗口上的日期、上班或下班标签对应本次确认的项目。

程序平时留在菜单栏，不在 Dock 中占用图标。无需每天手动打开，也无需让“终端”保持运行。

## 声音提醒

窗口出现时播放一次提示音，此后每隔约 30 秒再响一次：

| 第几次播放 | 提示音自身音量 |
| --- | --- |
| 第 1 次 | 20% |
| 第 2 次 | 40% |
| 第 3 次 | 60% |
| 第 4 次 | 80% |
| 第 5 次及以后 | 100% |

每条新提醒从 20% 重新开始。点击“已打卡”或紧急退出后，当前提示音停止。

实际响度取决于 Mac 系统音量、音效音量和声音输出设备。程序不会解除静音或改变系统音量；静音时可能听不到声音。

## 查看状态和试用提醒

点击菜单栏的“打卡”，可以选择：

- **显示提醒 / 今日状态**：有待确认项目时显示提醒，否则显示今天的确认状态。
- **演示提醒（不写记录）**：立即显示演示窗口，用于查看界面和试听声音。点击“已打卡”或“退出演示”即可关闭，不改变正式确认记录。
- **打开确认记录文件夹**：查看本机保存的记录。正常使用不需要编辑文件。
- **紧急退出（暂停 15 分钟）**：临时停止提醒。

不要为了关闭正式提醒而提前点击“已打卡”，否则当天对应时段不会再次提醒。

## 临时暂停和恢复

临时需要使用屏幕时，点击窗口或菜单栏里的“紧急退出（暂停 15 分钟）”，再选择“暂停并退出”。

暂停期间程序退出，菜单栏图标暂时消失；这不算已打卡。后台服务会在暂停到期后约 1 分钟内重新启动，继续提醒尚未确认的项目。电脑睡眠、未登录或系统繁忙时会推迟。

窗口获得键盘焦点时，也可按 `⌃⌥⌘Q` 进入紧急退出确认。普通的 Esc、⌘W、⌘M、⌘H 不会关闭提醒；⌘Q 会进入紧急退出确认。

要提前结束暂停，在“终端”执行：

```bash
"$HOME/Applications/ClockInReminder.app/Contents/MacOS/ClockInReminder" --resume
launchctl kickstart "gui/$(id -u)/local.clockin.reminder"
```

程序失去响应时，可通过 macOS“活动监视器”退出 `ClockInReminder`。后台服务可能再次启动它，永久停止请卸载。

## 睡眠、重启和遗漏提醒

- 电脑睡眠时不被本程序唤醒，唤醒后补出遗漏提醒。
- 重新登录或重启后，已经确认的项目不会重复提醒。
- 跨多天未确认时，按日期顺序逐项补提醒，不自动清除历史遗漏。
- 周六、周日不产生新提醒，但仍可能补出之前工作日的遗漏项。
- 不自动识别节假日、调休、请假或出差。周一至周五固定视为工作日。
- 切换 Mac 时区后，使用新时区的本地时间。

历史补提醒不能补交公司考勤，仍需按公司的补卡流程处理。

## 修改提醒时间

时间采用 24 小时制，第一个参数是上班时间，第二个参数是下班时间。要把登录自启时间改成 10:20 和 19:20，进入解压后的安装包目录，执行：

```bash
bash install.sh 10:20 19:20 --prebuilt
```

程序会更新启动配置，保留原来的确认记录。已确认的同日上班或下班项目，不会因为修改时间再次提醒。

安装时不提供时间参数，使用软件默认的 **10:00、19:10**；只提供上班时间时，下班仍为 19:10。本次使用的 10:10 是安装配置，不是软件默认值。

仅临时运行、不更新登录自启配置的命令：

```bash
"$HOME/Applications/ClockInReminder.app/Contents/MacOS/ClockInReminder" 10:20 19:20
```

临时运行前须退出已有实例；新参数不会改变正在运行的进程。日常修改时间优先使用安装脚本，以免下次登录恢复为原配置。双击 `.app` 不带时间参数，会使用软件默认时间。

## 卸载

打开“终端”，执行：

```bash
bash "$HOME/Applications/ClockInReminder.app/Contents/Resources/Support/uninstall.sh"
```

卸载会停止后台服务、删除程序及登录启动配置，默认保留本机确认记录。以后重新安装可以继续使用这些记录。

需要同时删除确认记录和日志时，执行下列命令；删除后无法通过本程序恢复，重装会从当天开始：

```bash
bash "$HOME/Applications/ClockInReminder.app/Contents/Resources/Support/uninstall.sh" --purge
```

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 菜单栏没有“打卡” | 检查是否在 15 分钟暂停期内；暂停结束后仍没有图标，可重新运行安装脚本 |
| 没听到提示音 | 检查静音、系统音效音量、耳机和声音输出设备；第一声只有自身音量的 20% |
| 窗口一直不消失 | 在考勤系统完成打卡后点击“已打卡”；有多项遗漏时须逐项确认，临时离开可使用紧急退出 |
| 提示记录保存失败 | 当前确认尚未保存，窗口会保留；检查磁盘空间和用户目录写入权限 |
| 修改时间后窗口没变 | 旧进程仍在运行；退出旧实例，再用安装脚本更新配置 |
| 周末弹出提醒 | 查看窗口日期，可能是之前工作日的遗漏提醒 |

本机确认记录：`~/Library/Application Support/ClockInReminder/confirmations.json`。

系统锁屏、注销和关机不受本程序阻止。程序没有接入公司账号或考勤接口，也不需要辅助功能、屏幕录制或管理员权限。
